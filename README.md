# COUNTRY HIGH · Boot Camp Shirt — Mockups

Mockups des **Boot-Camp-Shirts** für Claude Design. Öffentlich, damit Claude Design die Bilder
über eine URL lesen kann.

Produkt: Stanley/Stella **STTU169 Creator 2.0**, Bio-Baumwolle, DTG, Grössen S–2XL.
Druck: Brust links der COUNTRY HIGH Stern · Rücken `5 6 7 8 / BOOT CAMP / COUNTRY HIGH`

## Dateinamen

Beispiel: `BootCamp-Shirt_DesertDust_Back_3.jpg`

Dieselben Namen wie im pCloud-Archiv — ein Bild ist damit in beiden Ablagen auffindbar.

## Zwei Druckfarben

| Stoff | Druck | Kontrast |
|---|---|---|
| Black · French Navy · Burgundy · Khaki · Stargazer · Red | Cream | 5,2 : 1 bis 14,6 : 1 |
| Desert Dust · White | Ink | 8,9 : 1 und 17,8 : 1 |

Cream auf hellem Stoff liegt bei 1,3 : 1 bis 1,6 : 1 — über Saaldistanz praktisch unsichtbar.
Deshalb für helle Textilien die Ink-Fassung.
